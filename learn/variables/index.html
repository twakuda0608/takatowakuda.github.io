リスト（配列）とは？

リストは マンション に例えられます。マンション全体がリスト、各 部屋が要素、部屋番号がインデックス です。インデックスは 0 から 始まります。

2次配列

二次元リスト（2次配列）とは？

リストの中にリストを入れると、「たて × よこ」のマス目状データ（表・2次配列） を扱えます。
1次元リストが「1列の部屋」なら、2次配列は マンションの階（行）と号室（列） です。

🏢 行（たて）と 列（よこ）
外側のリストが行（何階か）、内側のリストが列（何号室か）を表します。
エクセルの表、カレンダー、座席表、チェス盤やオセロのマス目など、世の中の表形式データはすべて2次配列で表現できます。
🔍 matrix[i][j] の仕組み
matrix[0][2] のようにカッコを2つ並べます。
① matrix[0] で「0階のリスト [1, 2, 3]」を取り出し、
② その中の [2] 番目を取り出すため 3 にアクセスできます。

💡 二重forループですべてのマス目を調べる：
行 i と 列 j の二重ループを使うと、全マスを順番に取り出せます。
for i in range(3):
    for j in range(3):
        print(matrix[i][j])
二重ループ（i, j）の詳しい動きは 制御構文（二重ループ i と j） で学べます。
辞書

辞書（dictionary）とは？

リストは番号（0, 1, 2...）でデータを管理しましたが、「名前（キー）」と「値」のペア でデータを管理する仕組みが 辞書（dictionary / 辞書型） です。

🏷️ ラベル付きのロッカー
番号ではなく、"name" や "score" といった名前（キー）のラベルが貼られたロッカーに中身（値）を保管します。「太郎くんの点数は？」のように名前ですぐに取り出せます。
🔑 キー（Key）と 値（Value）
波かっこ { } と コロン : で書きます。
user = {"name": "タロウ", "score": 90}
キー "score" を指定すると、中身の 90 を瞬時に取り出せます。
辞書の中身（ロッカー一覧）

カードをクリックするとアクセス方法が見られます

3 件
Python コード
① 値の取り出し

キー名をカギカッコで指定します。

print(user["name"]) # → タロウ
② 追加・書き換え

新しいキーに代入するだけで追加されます。

user["city"] = "東京" # 追加 user["score"] = 95 # 更新
③ for文で中身を巡回

.items() でキーと値を両方取り出せます。

for k, v in user.items(): print(f"{k}: {v}")
